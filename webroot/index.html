Custom command

Optional shell commands. The lock command runs after the built-in actions; the unlock command runs before them.

Run as:

The lock command runs as root — a bad command can brick the device or break boot. Prefer shell unless you know exactly what the command does.

The unlock command runs as root — a bad command can brick the device or break boot. Prefer shell unless you know exactly what the command does.

Hold the boot-escape key while the daemon starts (just after you unlock the lock screen on boot) to unlock everything — recovery if you forget the combo.
